# Алтын Сөз: PWA пакеті

Файлдар:
- `index.html`: бес ойын бар негізгі бет (барлық код осы файлда)
- `manifest.json`: қосымшаның аты, түсі, иконалары
- `sw.js`: офлайн жұмыс үшін service worker
- `icon-192.png`, `icon-512.png`: қосымша иконалары

## 1. Интернетке шығару (тегін)

Қосымша тек HTTPS арқылы орнатылады. Төмендегі хостингтердің бәрі HTTPS береді.

**Netlify (ең оңайы)**
1. app.netlify.com сайтына кіріңіз.
2. «Add new site» → «Deploy manually» таңдаңыз.
3. Осы папканы (zip-ті ашып алған `altyn-soz-pwa` папкасын) беттің ішіне сүйреп апарыңыз.
4. Бірнеше секундтан кейін `https://....netlify.app` сілтемесі шығады.

**GitHub Pages**
1. GitHub-та жаңа репозиторий жасап, барлық файлды жүктеңіз.
2. Settings → Pages → Branch: `main`, папка: `/ (root)` таңдаңыз.

**Vercel**: vercel.com сайтында папканы жүктеп, «Deploy» басыңыз.

## 2. Телефонға орнату

- **Android (Chrome):** сілтемені ашып, ⋮ мәзірінен «Install app» немесе «Add to Home screen» таңдаңыз.
- **iPhone (Safari):** «Бөлісу» батырмасын басып, «На экран «Домой»» (Add to Home Screen) таңдаңыз.

Бір рет ашылған соң ойын интернетсіз де жұмыс істейді. Қаріптер алғаш рет интернетпен жүктеліп, кейін кэште сақталады.

## 3. Жаңартқанда

`index.html` немесе басқа файлды өзгерткен соң `sw.js` ішіндегі `VERSION` мәнін өзгертіңіз (мысалы, `altyn-soz-v2`) да, файлдарды қайта жүктеңіз. Әйтпесе телефондар ескі нұсқаны көрсетуі мүмкін.

## 4. Google Play-ге шығару

1. Алдымен 1-қадамды орындап, сайтыңыздың HTTPS сілтемесін алыңыз.
2. pwabuilder.com сайтына сілтемені енгізіп, «Package for stores» → Android таңдаңыз.
3. Шыққан `.aab` файлын Google Play Console-ға жүктейсіз (әзірлеуші аккаунты керек, бір реттік төлем).
4. Digital Asset Links баптауын PWABuilder нұсқауы бойынша аяқтаңыз, әйтпесе қосымшаның жоғарғы жағында браузер жолағы көрінеді.

## 5. App Store (iPhone)

Capacitor арқылы iOS жобасын жасап, Xcode-пен (Mac қажет) жібересіз. Apple Developer аккаунты керек. Алдымен Android нұсқасын шығарып көру жеңілірек.
